# ТЗ для Claude Code: VBA-решение «SmartCells» (Word ← Excel)

Ты — разработчик VBA для Microsoft Office. Собери решение по спецификации ниже. Все артефакты — в папку проекта. Комментарии в коде — на русском. В каждом модуле `Option Explicit`.

## 1. Что строим

Надстройка-макрос для Word: пользователь пишет в тексте документа метку вида `{A5}`, макрос заменяет её на значение этой ячейки из одного заранее заданного файла Excel (один фиксированный лист). Значения можно обновлять повторно — по кнопке и автоматически при открытии документа.

Среда клиента: Windows 10/11, Microsoft Office 2016+ / Microsoft 365 (настольный), один компьютер, файл Excel лежит локально. Локаль Office может быть русской. Разрядность Office — любая (32/64), поэтому если понадобятся Declare — только `PtrSafe`; лучше обойтись без WinAPI вообще.

## 2. Архитектурные решения (зафиксированы, не менять)

1. **Механика меток — Content Controls.** При первом обновлении каждая найденная в тексте метка `{адрес}` заменяется на plain-text Content Control: `Tag = "XL:" & адрес` (например `XL:A5`), `Title = "SmartCells"`, отображаемый текст — значение ячейки. Повторное обновление идёт уже не по тексту, а по всем CC документа с префиксом тега `XL:` — перечитать значение и заменить `.Range.Text`. Так связь с ячейкой живёт внутри документа, и метку не нужно вписывать заново.
2. **Excel читаем через late binding** (`CreateObject("Excel.Application")`), без ссылок на библиотеки в проекте. Книга открывается один раз на весь проход обновления: невидимо (`Visible=False`), `ReadOnly:=True`, `AddToMru:=False`; все нужные ячейки читаются за один сеанс; затем книга закрывается без сохранения и Excel завершается (`Quit`), объекты освобождаются. Никогда не открывать Excel по разу на каждую метку.
3. **Значение ячейки** — как отображается у пользователя: брать `rng.Text`. Если `rng.Text` состоит из решёток `#` (узкая колонка), fallback: `CStr(rng.Value2)`. Пустая ячейка → пустая строка не подставляется, см. обработку ошибок.
4. **Настройки** (полный путь к .xlsx и имя листа) — в реестре через `SaveSetting/GetSetting`, раздел `"NODA_SmartCells"`. Если настройки пусты при запуске обновления — сначала вызвать диалог настроек.
5. **Автообновление при открытии документа** — класс с `WithEvents App As Word.Application`, событие `DocumentOpen`: если в открытом документе есть хотя бы один CC с тегом-префиксом `XL:` — выполнить обновление. Экземпляр класса инициализируется процедурой `AutoExec` (решение живёт в глобальном шаблоне из STARTUP, поэтому `AutoExec` сработает при старте Word).

## 3. Публичные команды (имена процедур фиксированы)

- `ОбновитьДанные` — главная команда: (а) проход по тексту: найти все `{адрес}` и превратить в CC со значением; (б) проход по существующим CC `XL:*`: перечитать значения; (в) итоговое окно со сводкой: сколько обновлено, сколько проблем (список проблемных адресов, максимум первые 10).
- `НастройкиSmartCells` — диалог из двух шагов (можно `InputBox`): полный путь к файлу Excel (проверить существование файла) и имя листа (проверить наличие листа в книге — открыть на чтение и закрыть). Сохранить в реестр, показать подтверждение.
- `УбратьСвязьSmartCells` — по выделению или по всему документу (спросить `MsgBox` Да/Нет): заменить CC на их текущий текст (снять контролы, оставить значения). Нужна клиенту, чтобы «заморозить» документ перед отправкой наружу.

## 4. Правила разбора меток

- Шаблон метки в тексте: `{` + адрес + `}` без пробелов; адрес — 1–3 латинские буквы + 1–7 цифр (`A5`, `BC12`, `XFD1048576` не обязателен, но не должен ломать). Регистр букв не важен, в тег писать в верхнем.
- Кириллические буквы в адресе (`{А5}` с русской А) — частая ошибка пользователя: распознать такую метку и включить её в список проблемных с пояснением «адрес набран русскими буквами», текст метки в документе не трогать.
- Некорректный адрес / адрес вне сетки листа / лист или файл недоступны / ячейка с ошибкой Excel (`#ДЕЛ/0!` и т.п.) / пустая ячейка — метку или CC не затирать: подсветить жёлтой заливкой (`Shading`), включить в сводку проблем с причиной. При следующем успешном обновлении заливку снять.
- Файл Excel не найден по пути из настроек → одно понятное сообщение с текущим путём и подсказкой открыть `НастройкиSmartCells`; документ не менять вообще.

## 5. Артефакты на выходе (файлы проекта)

1. `src/SmartCells.bas` — основной модуль: команды из п.3, разбор меток, работа с Excel, сводка.
2. `src/AppEvents.cls` — класс событий приложения (DocumentOpen → автообновление).
3. `src/AutoExecInit.bas` — `AutoExec` + создание экземпляра AppEvents; сюда же (опционально) назначение сочетания `Ctrl+Shift+U` на `ОбновитьДанные` через `KeyBindings`.
4. `INSTALL.md` — пошаговая установка на машину клиента: создать документ, Alt+F11, импортировать три файла, сохранить как `SmartCells.dotm` в `%APPDATA%\Microsoft\Word\STARTUP`, перезапустить Word; включение макросов в Trust Center (путь по русскому интерфейсу Office); добавление кнопки «Обновить данные» на панель быстрого доступа (назначить на макрос `ОбновитьДанные`); как поменять путь/лист.
5. `make_test_files.py` — Python-скрипт (openpyxl + python-docx), который генерирует `test/Тест_данные.xlsx` (лист «Данные»: число с разделителями, дата, процент, длинный текст, формула, ячейка с ошибкой, пустая ячейка — каждая с назначенным форматом) и `test/Тест_документ.docx` с метками на все эти ячейки + одной кириллической меткой `{А1}` и одной заведомо кривой `{5A}`.
6. `TEST_PLAN.md` — чек-лист ручного прогона: первое обновление (метки → значения), правка значения в Excel → повторное обновление, каждая ошибочная ситуация из п.4, автообновление при повторном открытии документа, `УбратьСвязьSmartCells`.

## 6. Требования к коду

- `Option Explicit` везде; обработка ошибок `On Error` с гарантированным закрытием Excel (`Quit`) и освобождением объектов в `Finally`-паттерне (метка выхода) — Excel не должен зависать в процессах даже при сбое посреди прохода.
- `Application.ScreenUpdating = False` на время прохода, вернуть в `True` в любом исходе.
- Не использовать `Selection` для замен — только `Range`; не ломать форматирование окружающего текста (CC наследует формат точки вставки).
- Замены выполнять с конца документа к началу (или через повторный `Execute` от начала), чтобы позиции не съезжали.
- Ничего не писать в файл Excel клиента; книгу открывать только ReadOnly.
- Строки интерфейса (сообщения, сводка) — на русском.

## 7. Критерии приёмки

- На сгенерированных тестовых файлах: первый запуск `ОбновитьДанные` заменяет все корректные метки значениями с сохранением форматов отображения; кривая и кириллическая метки подсвечены и перечислены в сводке; после изменения ячейки в Excel повторный запуск обновляет значение без повторного ввода меток; при закрытом и переоткрытом документе значения обновляются автоматически; после `УбратьСвязьSmartCells` документ не содержит CC, значения на месте; в диспетчере задач не остаётся висящих процессов Excel после любого сценария, включая ошибку «файл не найден».

## 8. Вне объёма (не делать)

Диапазоны и таблицы, несколько файлов/листов, выбор файла диалогом при каждом запуске, запись из Word в Excel, поддержка macOS и облачных путей (OneDrive/SharePoint), Ribbon XML (кнопка — только QAT по инструкции), инсталлятор.

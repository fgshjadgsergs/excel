# Установка надстройки SmartCells

Пошаговая инструкция для машины клиента (Windows 10/11, Microsoft Office
2016+ / Microsoft 365, настольный, русский интерфейс).

---

## Шаг 1. Создать документ-заготовку и открыть редактор VBA

1. Запустите Word, создайте новый пустой документ.
2. Нажмите **Alt + F11** — откроется редактор Visual Basic (VBE).

## Шаг 2. Импортировать три файла проекта

В редакторе VBA: меню **File → Import File…** (Файл → Импорт файла…) и по
очереди импортируйте три файла из папки `src`:

- `src/SmartCells.bas`
- `src/AppEvents.cls`
- `src/AutoExecInit.bas`

После импорта в окне **Project** должны появиться модули `SmartCells`,
`AutoExecInit` и класс `AppEvents`.

## Шаг 3. Сохранить как глобальный шаблон в папке STARTUP

1. Вернитесь в Word (**Alt + F11** переключает обратно).
2. **Файл → Сохранить как**.
3. Тип файла — **Шаблон Word с поддержкой макросов (\*.dotm)**.
4. Имя файла — `SmartCells.dotm`.
5. Сохраните в папку автозагрузки Word:

   ```
   %APPDATA%\Microsoft\Word\STARTUP
   ```

   Чтобы быстро открыть эту папку: **Win + R**, вставьте путь выше, **Enter**.
   Если папки `STARTUP` нет — создайте её.

6. Закройте и снова запустите Word.

> Шаблон из папки `STARTUP` загружается при каждом старте Word как глобальная
> надстройка, поэтому процедура `AutoExec` срабатывает автоматически:
> включается автообновление при открытии документов и назначается
> горячая клавиша **Ctrl + Shift + U**.

## Шаг 4. Разрешить макросы (Центр управления безопасностью)

1. **Файл → Параметры → Центр управления безопасностью →
   Параметры центра управления безопасностью…**
2. Раздел **Параметры макросов**:
   - выберите **Отключить макросы с уведомлением** (рекомендуется) либо,
     если политика позволяет, «Включить все макросы».
3. Раздел **Надёжные расположения** — при необходимости добавьте папку
   `%APPDATA%\Microsoft\Word\STARTUP` как надёжное расположение, чтобы
   надстройка запускалась без предупреждений.
4. Нажмите **OK**, перезапустите Word.

## Шаг 5. Задать путь к файлу Excel и имя листа

Запустите макрос **`НастройкиSmartCells`** (см. как запускать макрос ниже) и
укажите:

1. полный путь к файлу `.xlsx` (файл должен существовать);
2. имя листа (проверяется наличие листа в книге).

Настройки сохраняются в реестре (раздел `NODA_SmartCells`) и запоминаются
между сеансами.

## Шаг 6. Кнопка «Обновить данные» на панели быстрого доступа (QAT)

1. Щёлкните стрелку **Настройка панели быстрого доступа** (справа от кнопок
   сохранения вверху окна) → **Другие команды…**.
2. В списке **Выбрать команды из** выберите **Макросы**.
3. Найдите макрос **`ОбновитьДанные`**, нажмите **Добавить >>**.
4. При желании нажмите **Изменить…** и выберите значок и подпись
   «Обновить данные».
5. **OK**. Теперь кнопка обновления доступна одним щелчком.

---

## Как запускать макрос вручную

**Вид → Макросы → Макросы** (или **Alt + F8**), выберите нужное имя
(`ОбновитьДанные`, `НастройкиSmartCells`, `УбратьСвязьSmartCells`) →
**Выполнить**.

Горячая клавиша обновления: **Ctrl + Shift + U**.

## Как поменять путь к файлу или имя листа

Запустите **`НастройкиSmartCells`** ещё раз и введите новые значения —
они перезапишут прежние настройки.

## Команды надстройки

| Команда                  | Что делает                                                        |
|--------------------------|-------------------------------------------------------------------|
| `ОбновитьДанные`         | Заменяет метки `{адрес}` значениями и обновляет уже связанные CC. |
| `НастройкиSmartCells`    | Задаёт путь к файлу Excel и имя листа.                            |
| `УбратьСвязьSmartCells`  | Снимает связь (замораживает значения) — весь документ/выделение.  |

---

## Удаление надстройки

Закройте Word, удалите файл `SmartCells.dotm` из папки
`%APPDATA%\Microsoft\Word\STARTUP`, снова запустите Word.

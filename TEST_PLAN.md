# План ручного тестирования SmartCells

Чек-лист прогона на сгенерированных тестовых файлах. Перед началом
выполните `python make_test_files.py` — появятся `test/Тест_данные.xlsx`
(лист «Данные») и `test/Тест_документ.docx`.

## Подготовка

- [ ] Надстройка установлена по `INSTALL.md`, макросы разрешены.
- [ ] На вкладке **«Надстройки»** есть панель **SmartCells** с тремя
      кнопками (появилась сама после перезапуска Word).
- [ ] Нажата кнопка **Настройки**: путь = `…\test\Тест_данные.xlsx`,
      лист = `Данные`. Показано подтверждение сохранения.
- [ ] Открыт `test/Тест_документ.docx`.

## 1. Первое обновление (метки → значения)

- [ ] Нажать кнопку **Обновить данные** (или **Ctrl + Shift + U**).
- [ ] `{A1}` → число с разделителями разрядов (формат сохранён).
- [ ] `{A2}` → дата в формате ДД.ММ.ГГГГ.
- [ ] `{A3}` → процент (например `25,6%`).
- [ ] `{A4}` → длинный текст, форматирование абзаца не сломано.
- [ ] `{A5}` → значение формулы (= A1 × 2).
- [ ] `{Лист2!A1}` → «Значение со второго листа» (метка с указанием листа).
- [ ] Метки заменены на Content Control (при клике видна рамка контрола).
- [ ] Итоговое окно: «Обновлено ячеек: 6» и список проблем.

## 1a. Метки с указанием листа

- [ ] `{Лист2!A1}` подставилось значение именно со второго листа.
- [ ] Временно указать в метке несуществующий лист (например
      `{НетТакого!A1}`) и обновить → метка подсвечена жёлтым, в сводке:
      «лист «НетТакого» не найден».

## 2. Ошибочные ситуации (п.4 ТЗ)

- [ ] `{А1}` (кириллическая А) — подсвечена жёлтым, текст не изменён,
      в сводке: «адрес набран русскими буквами».
- [ ] `{5A}` (кривой адрес) — подсвечена жёлтым, в сводке:
      «некорректный адрес».
- [ ] `{A6}` — ячейка с ошибкой `#ДЕЛ/0!`: CC подсвечен жёлтым,
      значение не подставлено, в сводке — причина «ошибка в ячейке».
- [ ] `{A7}` — пустая ячейка: CC подсвечен жёлтым, пустая строка не
      подставлена, в сводке — «пустая ячейка».

## 3. Повторное обновление после правки Excel

- [ ] **Сразу повторно** запустить `ОбновитьДанные` (ничего не меняя):
      прогон завершается штатно, без ошибок VBA — несмотря на то, что
      в документе остались CC с текстом меток `{A6}`/`{A7}` (проблемные
      ячейки). Это ключевая проверка: метки внутри CC не должны
      оборачиваться повторно.
- [ ] В `Тест_данные.xlsx` изменить `A1` (например на `9 000 000`),
      сохранить, закрыть Excel.
- [ ] В документе снова запустить `ОбновитьДанные`.
- [ ] Значение `{A1}` (и зависимой формулы `{A5}`) обновилось **без**
      повторного ввода метки — связь живёт в CC.
- [ ] Заполнить `A7` в Excel → повторное обновление: жёлтая подсветка
      с этой ячейки снята, значение подставлено.

## 3a. Обычный текст в фигурных скобках

- [ ] Вписать в документ `{Итого}` и `{примечание 1}` → обновить:
      текст НЕ подсвечен, в сводку проблем не попал (не похож на адрес).
- [ ] Метка `{5A}` при этом по-прежнему помечается как некорректная.

## 3b. Прочие граничные случаи

- [ ] Нажать «Обновить данные» при **закрытых всех документах** —
      вежливое сообщение «Нет открытого документа», а не ошибка VBA.
- [ ] В `НастройкиSmartCells` вставить путь **в кавычках** (как копирует
      Проводник через «Копировать как путь») — кавычки снимаются,
      путь принимается.
- [ ] Ячейка с переносом строки (Alt+Enter в Excel) — подставляется
      одной строкой (переносы заменены пробелами), без ошибок.
- [ ] Узкая колонка с датой (в ячейке видно `####`) — в документ
      подставляется **дата**, а не серийное число.

## 4. Автообновление при открытии

- [ ] Сохранить и закрыть `Тест_документ.docx`.
- [ ] Изменить значение `A1` в Excel, сохранить, закрыть.
- [ ] Снова открыть `Тест_документ.docx`.
- [ ] Значения обновились **автоматически** (сработало событие
      DocumentOpen), появилось итоговое окно.

## 5. Снятие связи (`УбратьСвязьSmartCells`)

- [ ] Запустить `УбратьСвязьSmartCells`, ответить «Да» (весь документ).
- [ ] Content Control-ы исчезли (рамок нет), значения остались на месте.
- [ ] Повторный `ОбновитьДанные` эти значения больше не трогает
      (связь снята).

## 6. Файл Excel недоступен

- [ ] В `НастройкиSmartCells` временно указать несуществующий путь
      (или переименовать xlsx).
- [ ] Запустить `ОбновитьДанные` — одно понятное сообщение с текущим
      путём и подсказкой открыть `НастройкиSmartCells`.
- [ ] Документ **не изменён**.
- [ ] В **Диспетчере задач** нет висящих процессов `EXCEL.EXE`.
- [ ] В `НастройкиSmartCells` указать существующий файл, но **занятый
      другим пользователем/процессом с блокировкой** (или битый файл) —
      сообщение говорит про книгу («не удалось открыть книгу»),
      а НЕ ложное «лист не найден».

## 6a. Горячая клавиша и Normal.dotm

- [ ] **Ctrl + Shift + U** реально запускает обновление.
- [ ] Закрыть Word — НЕТ вопроса «Сохранить изменения в Normal.dotm?»
      (надстройка не трогает Normal).

## 7. Отсутствие висящих процессов Excel

- [ ] После каждого сценария (в т.ч. с ошибками) в Диспетчере задач
      нет оставшихся процессов `EXCEL.EXE`.
